**Top 10 Technical Papers Fast Forward**

We present VR-Doh, an intuitive system for 3D object creation and manipulation in Virtual Reality. Using the Material Point Method (MPM) for real-time elastoplastic object simulation, our system enables sculpting, deforming, and editing objects through natural hand interactions. We support modeling diverse objects like food, characters, and structures with real-time performance through localized simulation techniques and seamless rendering with 3D Gaussian Splatting.
